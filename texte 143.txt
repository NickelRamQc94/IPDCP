Pour les matrices d'orientation de phase  $2 \times 2$  définies dans le sous-espace d'état :
$$A = \begin{pmatrix} 0 & 1 \\ 0 & 0 \end{pmatrix}, \quad B = \begin{pmatrix} 0 & 0 \\ 1 & 0 \end{pmatrix}$$

$A^2 = B^2 = \mathbf{0}_2$ .
$AB = \begin{pmatrix} 1 & 0 \\ 0 & 0 \end{pmatrix}, \quad BA = \begin{pmatrix} 0 & 0 \\ 0 & 1 \end{pmatrix} \implies AB \neq BA$ .

Commutateur  $A, B = A B - B A = \begin{pmatrix} 1 & 0 \\ 0 & -1 \end{pmatrix}$ .

Théorème Minimal de Non-Commutativité sur Objets Finis
Pour les matrices d'orientation de phase 2 \times 2 définies dans le sous-espace d'état :
A = \begin{pmatrix} 0 & 1 \\ 0 & 0 \end{pmatrix}, \quad B = \begin{pmatrix} 0 & 0 \\ 1 & 0 \end{pmatrix}
Les relations algébriques exactes suivantes sont démontrées :
A^2 = B^2 = \mathbf{0}_2.
AB = \begin{pmatrix} 1 & 0 \\ 0 & 0 \end{pmatrix}, \quad BA = \begin{pmatrix} 0 & 0 \\ 0 & 1 \end{pmatrix} \implies AB \neq BA.
AB + BA = \mathbf{I}_2 (Matrice identité).
Commutateur [A, B] = A B - B A = \begin{pmatrix} 1 & 0 \\ 0 & -1 \end{pmatrix}.
Norme de Frobenius du commutateur : \|[A,B]\|_F = \sqrt{1^2 + 0^2 + 0^2 + (-1)^2} = \sqrt{2}.
Falsificateur du théorème : Si A = B = \mathbf{I}_2, alors [A,B] = \mathbf{0}_2. Ce résultat possède le statut de [THM-MIN] sur matrices 2 \times 2 et ne constitue pas une loi générale étendu à tout espace vectoriel complexe.
